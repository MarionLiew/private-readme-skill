# private-readme

私人项目 README 规范：面向三份读者（半年后的自己 / AI 助手 / 未来转开源的读者），回答"怎么跑起来、改到哪了、什么别动"。

Companion to [open-source-readme-skill](https://github.com/MarionLiew/open-source-readme-skill) — 那个管开源 README 怎么对陌生人说话，这个管私有 README 怎么让项目和 AI 会话能续上命。反 AI 味 / 语气硬规则内联自那边，两份标准可独立使用。

## Install

```bash
hermes skills install https://raw.githubusercontent.com/MarionLiew/private-readme-skill/main/SKILL.md --name private-readme
```

Or copy `SKILL.md` into `~/.hermes/skills/`.

## Contains

- `SKILL.md` — the standard itself（三层读者定位、Quick start 优先的结构、Roadmap/TODO 写法、`<!-- internal -->` 转开源预埋、AI 可读性规则）
